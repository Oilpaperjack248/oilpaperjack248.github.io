## 📋 Пошаговый запуск 24/7 на Render (Бесплатно)

В `server.js` уже встроено ВСЁ в один процесс:
- Раздача веб-приложения (`index.html`).
- REST API для базы игроков, реферальной системы (10%), переводов, биржи, банов и префиксов.
- Автоматический запуск Telegram-бота (`bot.js`).

### Шаг 1. Загрузите файлы в GitHub
1. Создайте репозиторий на [github.com](https://github.com) (например, `carddrop-app`).
2. Загрузите файлы:
   - `index.html`
   - `server.js`
   - `bot.js`
   - `package.json`
   - `README.md`

### Шаг 2. Создайте Web Service на Render.com
1. Зарегистрируйтесь на [render.com](https://render.com).
2. Нажмите **«New +»** → **«Web Service»** и выберите ваш репозиторий.
3. Параметры:
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: `Free` ($0/month)
4. В разделе **«Environment Variables»** добавьте:
   - `BOT_TOKEN` = `ВАШ_ТОКЕН_ОТ_BOTFATHER`
   - `WEBAPP_URL` = ссылка на Render (например, `https://carddrop-app.onrender.com`)
   - `ADMIN_PASSWORD` = `1190234`
5. Нажмите **«Deploy Web Service»**.

### Шаг 3. Подключение к @BotFather
1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/mybots` → выберите вашего бота.
2. **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Укажите ссылку с Render: `https://carddrop-app.onrender.com`
4. Введите название кнопки: `Играть 💳`.

### Шаг 4. Чтобы сервер никогда не спал (Пинг 24/7)
1. Зайдите на бесплатный [cron-job.org](https://cron-job.org) или [uptimerobot.com](https://uptimerobot.com).
2. Поставьте HTTP-монитор с интервалом раз в 10 минут на URL:  
   `https://carddrop-app.onrender.com/api/leaderboard`
3. Сервер и бот будут работать **круглые сутки без задержек и отключений**!
